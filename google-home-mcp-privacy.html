Privacy Policy for Jer Google Home MCP

Effective Date: October 2, 2026 | Publisher: Power Users Lab

Overview

Jer Google Home MCP is a personal tool, not a public product. It lets its one user connect their own Google Home account to their own AI assistant (Claude, by Anthropic) so the assistant can read and control the smart-home devices in their own home. It is not offered to the public, and no one else's account is used.

What Data Does It Access?

With the user's permission (the Google Home API scope home.platform.v2), the tool can access the user's Google Home data:

Data Why
Homes, rooms and devices To know which lights, speakers, displays and cameras exist.
Device state (on/off, brightness, color) To report and change what the devices are doing.
Device and camera history (events and descriptions) To answer questions such as "was anyone in the office" and to support reminders and safety alerts.
Device commands (lights, speaker announcements) To carry out the user's requests.

Where Data Goes

Google Home data is requested only when the user asks their assistant to do something. The results are passed to the user's own Claude conversation so the assistant can answer, and are handled under Anthropic's privacy policy. Power Users Lab runs no server for this tool and does not receive, store, sell or share any of this data.

The sign-in tokens Google issues are stored only on the user's own computer.

Google API Services User Data Policy

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Data is not used for advertising and is not used to train general-purpose AI models.

Your Control

Access can be removed at any time at myaccount.google.com/permissions. Deleting the local token file also ends access from that computer.

Changes to This Policy

If this policy changes, the revised version will be posted here with a new effective date.
